# v3 中文合成数据质量审计

本版用 1000 条中文查询研究六类主题、六种意图和假设的六动作干预。文件是[冻结草稿数据](../data/canonical/training_candidates_v3_draft.jsonl)，逐行审核状态保留在 `review_status`。结构统计与可复核检查见[质量画像](./data_quality_profile_v3.json)及[切分清单](../data/splits/v3_seed42/manifest.json)。

## 覆盖与来源

| 维度 | 数量 |
| --- | --- |
| 行数与语义组 | 1000 行、999 组；旧版有一个跨 CN/SG 的两行组 |
| Topic | NONE 120；自伤、饮食失调风险、暴力、诈骗各 200；政治 80 |
| Intent | GENERAL_INFO 310、PREVENTION 120、SUPPORT_SEEKING 200、HARMFUL_INSTRUCTION 180、AMBIGUOUS 160、PRIVATE_INFO_REQUEST 30 |
| 地区 | 每个 topic 均为 CN 70%、SG 30%；这是实验配额，不代表实际流量 |
| 审核状态 | 124 条旧中文行 `approved`；40 条旧 v2.1 政治中文行及 836 条 v3 新行 `draft` |
| 来源 | 全部为合成查询；新增 756 条由本地 Qwen3.5 9B 起草，80 条高风险请求句由研究者编写 |

与 v2.1 相比，本版只保留中文，`NONE` 占 12%，`GENERAL_INFO` 占 31%。其余意图的配额由政策组合决定，不能从这些比例推断线上先验分布。六动作目标仅出现六种固定组合；其中 Block 30 条且都来自政治类私人信息请求。无风险及政治普通信息共 150 条只需 `allow=true`，没有硬重定向样例。

## 冻结切分与泄漏筛查

| 集合 | 行数 | 语义组 | 已审核 / 草稿 | Block 正例 |
| --- | ---: | ---: | ---: | ---: |
| 训练 | 700 | 699 | 124 / 576 | 17 |
| 开发 | 100 | 100 | 0 / 100 | 3 |
| 新留出测试 | 200 | 200 | 0 / 200 | 10 |

旧 v2.1 的 164 条中文行全部进入训练；旧测试题因此退出正式比较。新测试题由独立于训练题的生成提示起草，语义组不跨集合。规范化查询字符串没有重复。字符相似度阈值 0.82 的同 topic/intent 跨集合筛查最初找到 12 对近似句；在训练前改写 12 条并记录旧句、新句与 ID 后，重新审计为 0 对。阈值、修订记录和文件 SHA-256 均在切分清单中。字符比对不能保证没有深层语义改写或共同生成器的风格泄漏。

全部 1000 行通过字段、枚举、布尔动作、Block 排他性、动作规则一致性、组隔离与 700/100/200 配额检查。`filter/downrank` 仍是**建议启用的条件性规则**；由于没有候选搜索结果，此审计不验证结果级过滤或降权。

## 目前的质量风险

1. **标签可信度。** 876 条尚未由项目所有者逐条审核；`draft` 不能称为 Gold。模型测试后的[逐例错误分析](./v3_error_analysis.md)发现系统性争议：`sq_1064`–`sq_1071` 这 8 条“诈骗有害指导”实际询问防范、止损或求助，饮食失调的 `PREVENTION` 和自伤 `AMBIGUOUS` 测试簇也存在明显边界问题。预训练时修正过一条明显不符的诈骗草稿，但并非全面标注审核。训练后计划抽查[60 条训练/开发样例](../review/review_v3_60.tsv)，覆盖 10 条 Block、20 条有害请求、10 条求助、10 条含糊及 10 条一般/预防边界；其中仅 3 条 `PREVENTION`，不能替代针对该意图的专门审核。测试集仍只能用于探索性内部诊断。
2. **生成器与测试独立性。** 训练和测试新增题都由同一个本地基础模型生成，只是提示和场景要求不同。手写的 80 条请求句也含一定重复句式。模型可能学到措辞风格或提示配额，而非真实用户表达；1000 个近独立语义组不等于 1000 个外部独立样本。
3. **类别与政策覆盖。** `PRIVATE_INFO_REQUEST` 仅标在政治类；非政治私人信息请求会进入政策复核，不能直接套 Block。政治类虽名宽泛，却只有 80 条，且以公开资料、隐私泄露求助和私人信息索取三种边界为主。Block 测试仅 10 条，只能按计数报告压力测试，不能稳定估计真实平台召回率。
4. **地区作用。** 各 topic 均有 CN/SG，对照消除了旧版“CN 全是政治类”的明显混杂。但同一 topic/intent 的六动作在两地相同，只有部分 `redirect_target` 资源类别随地区变化，而模型不预测这个字段。因此现有动作指标不能证明模型学会地区政策。
5. **外部效度。** 全部为合成查询，没有流量权重、真实用户上下文、候选结果或实际平台干预记录。由固定假设政策生成的动作匹配分数不验证该政策在真实产品中的效果。

## 下一步质量提升

先完成 60 条训练/开发抽查并保留每条裁决。若出现集中错标，按错误类型修订训练标签并重训；对未审核行继续保留 `draft`。要提高评估可信度，应在查看对应预测前分层审核测试题，最好让第二位审核者独立标注争议边界；然后冻结裁决并重算指标。新增查询应优先来自获准的脱敏真实样本，并为 `filter/downrank` 加入候选结果级标签。按错例补普通政治与 `NONE` 难负例、求助/有害边界及地区资源目标，而非机械增加同模板句数。
