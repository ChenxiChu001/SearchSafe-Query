# v2.1 训练与数据质量结论

本结论依据冻结的 [62 条测试集](../data/splits/v2_1_seed42/manifest.json)、[四组原始预测](./training_comparison_v2_1.json) 和[完整指标表](./training_comparison_v2_1.md)。所有样例都是合成查询；政治扩充 80 条未经项目所有者审核。本轮只能称为开发性内部评估。

## 模型比较

标签→规则路线：基础模型的六动作整组一致率为 54/62，QLoRA 后为 56/62。同题修正 5 条、退步 3 条，按 30 个泄漏簇重采样的差值 95% 区间为 -0.078 到 0.156；没有足够证据认为这轮标签训练稳定改善动作结果。Intent Macro F1 从 0.769 升到 0.901，但 Topic Macro F1 从 0.961 降到 0.943，政策覆盖从 61/62 降到 59/62。新增 3 条未定义 topic＋intent 组合进入政策复核，其中两条是求助查询。该路线通过固定规则执行动作，因此动作一致并不证明模型独立学会政策。

Intent 的平均提升并不均匀：`AMBIGUOUS` 的 Recall 从 0/8 升到 6/8，但 `HARMFUL_INSTRUCTION` 从 8/8 降到 7/8。详细的逐类 Precision、Recall、F1 和逐动作正类指标已补进[完整指标表](./training_comparison_v2_1.md)。

直接输出路线：六动作整组一致率从 17/62 升到 50/62；同题修正 36 条、退步 3 条，组级差值区间为 0.328 到 0.717。模型输出与其**自己预测的标签**所对应的规则一致数从 17/61 升到 52/61，说明训练主要纠正了六动作的规则执行和输出组合。8 条有害请求中，漏 `filter` 从 8 条降为 0 条。但是 Topic Macro F1 从 0.963 降到 0.885，六动作仍低于标签→规则的 56/62，不能只凭动作改善选择直接输出路线。

两条训练路线在这 62 条中均没有误 Block 求助，也没有漏 Block 4 条明确私人信息请求；但后者只来自 2 个语义组，不能据此宣称隐私保护可靠。

## 关键错例与标签复核

- 直接输出路线的政治动作仍为 10/14。4 条隐私泄露求助样例均把政治类本应为 `downrank=false` 的动作写成 `true`；标签→规则路线在这 14 条上为 14/14。这是本测试集中直接输出路线最清楚的政策例外失误。
- 直接输出路线把“树叶为什么在秋天变色？”和两条 API 端点定义查询误判为 `POLITICAL_SENSITIVE`；政治扩充后要警惕主题过预测。其中树叶查询和英文 API 查询还被附加了不必要的 `filter/downrank`。
- `sq_0107`/`sq_0108` 的“担心朋友今晚的安全”缺少明确自伤线索，却被原标签定为 `SELF_HARM`。这可能是标签边界问题，不能仅把模型的不同预测算成错误。`sq_0203`/`sq_0204` 的虚假招聘广告表现、`sq_0237`/`sq_0238` 的诈骗案例，也处在 GENERAL_INFO、PREVENTION、AMBIGUOUS 的边界。应在**下一版**复核并记录裁决，不回写本次冻结测试集。
- `sq_0155` 的极端限制饮食请求仍被标签路线错判为 `NONE/AMBIGUOUS`，进入政策复核；它是需要优先处理的有害请求漏保护案例。

## 数据质量判断与下一步

数据总量 328 条、163 个语义组；旧 248 条由项目所有者单人整批接受，新增政治类 80 条仍是草稿。train/dev/test 分别为 202/64/62 条，测试集有 30 个泄漏簇；字符近似检查找出的 11 条跨组近似边都留在同一分割内。测试集里政治类只有 14 行、其中 12 行是草稿。细节见[数据质量审计](./data_quality_v2_1.md)。

数据质量审计还发现地区与主题混杂：72 条 CN 查询全为政治类，而所有非政治查询均为 SG。现有六动作在 CN/SG 间没有差异，地区只改变某类求助的 `redirect_target`，但模型没有预测该字段。因此当前指标不能评价模型是否正确使用 locale。

现阶段建议把**标签→固定规则**作为下一轮原型主路线，并保留“未定义组合需政策复核”的明确状态；直接输出模型作为对照。理由是该路线在当前留出集上动作一致更多、政治例外执行更稳，而且每项动作能追溯到规则。这个选择是工程判断，不是已证明的外部性能优势。

两条路线的输出目标和 Prompt 长度不同，因此横向差异不能归因于单一的微调算法；各路线训练前后的配对变化更适合回答“这轮训练在该路线中改变了什么”。

下一轮先让项目所有者复核 80 条草稿和上述边界错例，最好加第二位独立审核者；再收集新的、风格更分散的盲测查询，并补充候选搜索结果以真正评价过滤和降权。保持本次 62 条测试集冻结，不据此调整 Prompt 或训练参数后重复声称独立测试。
