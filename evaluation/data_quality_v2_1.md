# v2.1 训练候选集质量审计

本次训练输入为 `data/canonical/training_candidates_v2_1.jsonl`。旧 248 条由项目所有者单人复核后整批接受，另新增 80 条未经其审核的政治类合成草稿。本文只报告可从文件核查的质量，不把 `draft` 视为 Gold。

| 项目 | 数量与状态 |

| 总量 | 328 条；163 个语义组；中英各 164 条 |
|        |                                                              |
|        |                                                              |

政治类从 10 条扩到 90 条，但仅覆盖已定义的公开信息、隐私泄露求助、明确索取私人信息三个 intent。名称很宽，不能据此推断所有政治语境都已覆盖。所有新样例仍是合成查询，缺少真实搜索结果和真实分布。

## 结构与泄漏控制

`scripts/schema_v2.py` 检查字段、枚举、重复查询、翻译组标签一致性、Block 排他和 Redirect 目标。328 条通过结构校验；这不能替代内容审核。

可复核的[质量画像](./data_quality_profile_v2_1.json)由 `scripts/audit_dataset_v2_1.py` 生成：14 个必填字段无缺失或空字符串，ID 和规范化后的“查询＋地区”键均无重复。`redirect_target` 有 192 个 `null`，恰好对应 192 条 `redirect=false`，属于预期值。六动作只出现 6 种组合，反映固定假设政策的有限输出空间。

切分前用同 topic/intent/语言、字符相似度至少 0.77 的规则找出 11 条跨语义组近似边，并把相连语义组作为同一个泄漏簇分配。阈值和边保存在 `data/splits/v2_1_seed42/manifest.json`，需要人工检查漏掉的语义近义例。已核验这 11 条边均未跨 train/dev/test。

另对同语言、不同标签的所有样例对做字符相似度扫描：阈值 0.76 以上仅有一对，分别是“彗星与小行星的区别”和“冲突与袭击的区别”，相似来自句式而非同一语义。这个扫描不能发现改写幅度较大的标签冲突。

冻结后：train 202 条（146 approved、56 draft），dev 64 条（52 approved、12 draft），test 62 条（50 approved、12 draft）。测试集中的政治类 14 行、隐私请求 4 行；后者只有 2 个语义组，任何 Block 指标都应附原始计数。旧 248 条已经用于此前 Prompt 基线和错误分析，因此这里是**内部留出评估**，不是完全未接触的外部盲测。

## 适用性判断

| 维度 | 证据 | 判断及影响 |
| --- | --- | --- |
| 结构与版本 | 328/328 通过规则校验；0 个重复 ID、0 个重复查询＋地区键；冻结文件哈希一致 | **适合**可复现的训练管线和标注规范演示 |
| 语义独立性 | 163 个语义组；测试 62 行只代表 30 个泄漏簇；已知的 11 条跨组近似边不跨切分 | **部分满足**内部留出；字符相似度不能排除所有语义近义泄漏 |
| 标签可信度 | 248 条仅单人整批接受；80 条草稿未经用户审核；边界错例见[评估结论](./assessment_v2_1.md) | **不足以称为独立 Gold**；模型与标签不一致时仍需人工裁决 |
| 地区可识别性 | 72/72 条 CN 查询全为政治类；SG 的政治类为 18/256 条 | **高风险混杂**：地区和主题相关，无法测出 CN 非政治查询的误判率 |
| 地区策略差异 | 现有 topic＋intent 组合的六动作在 CN/SG 间有 0 种差异；只有政治隐私泄露求助的 `redirect_target` 资源类别随地区变化 | **不能用当前输出指标声称学会地区规则**；模型不预测 `redirect_target` |
| 真实分布与结果处理 | 328/328 为合成查询；没有真实查询分布、候选结果或真实处置记录 | **不适合**估计线上 Precision/Recall、实际过滤或降权效果 |

因此，本数据集**适合假设政策原型、训练链路与错误分析练习**；目前**不适合证明真实搜索系统的安全效果或地区策略能力**。政治类占 90/328，来自设计配额，不能当作真实流量占比；六动作只有 6 种目标组合，也使直接输出任务比实际搜索干预简单。

这是一份静态合成语料，没有事件时间或采集时间字段，故不适用线上数据的“新鲜度”检查，也无法分析用户查询分布随时间的变化。

下一轮最小修复：先复核 80 条政治草稿和 `sq_0107`/`sq_0108` 等边界例；再找第二位审核者盲标跨 topic/intent 的分层样本，记录分歧与裁决。新增 CN 非政治查询和 CN/SG 同义对照，解除地区与主题的混杂；若要验证地区资源选择，就把 `redirect_target` 纳入输出与评估。另建风格更分散的新盲测集，不改写本轮冻结的 62 条测试集；评价 `filter/downrank` 时还需加入候选结果及结果级标签。

## 不能从本数据推出的结论

- 单人审核不能计算跨标注员一致性；整批接受也没有逐条裁决证据。
- 六动作由假设政策规则起草；匹配标签不等于真实过滤或降权了候选结果。
- `redirect_target` 只是资源类别描述，没有验证具体资源可达性、相关性或隐藏导向的用户理解。
- 政治类新增 80 条仍需项目所有者后续复核；本轮政治训练与量化指标只作开发性诊断。
